# Сайт Зуляль Ушуровой — автономная версия

Этот архив содержит финальную версию сайта `9ff797a6`, исходный код и готовую production-сборку. Все изображения и видео, использованные на странице, находятся внутри архива: сайт не зависит от `/manus-storage`.

## Быстрый запуск на Windows

Для локального просмотра откройте PowerShell в папке `dist/public` и выполните:

```powershell
py -m http.server 8080
```

Затем откройте в браузере `http://localhost:8080`. Чтобы остановить локальный сервер, нажмите `Ctrl + C` в PowerShell.

## Загрузка на статический хостинг

Для обычного хостинга, FTP, Netlify, Cloudflare Pages или GitHub Pages загрузите **всё содержимое** папки `dist/public` в корневую папку сайта. Не загружайте папку `public` как отдельную вложенную директорию: файл `index.html`, папки `assets` и `media` должны находиться в корне сайта.

## Доработка исходного кода

Исходные файлы расположены в `client/src`. Тексты и структура страницы находятся в `client/src/pages/Home.tsx`, а визуальные стили — в `client/src/index.css`. После изменений запустите в корне архива:

```powershell
pnpm install
pnpm build
```

Для публикации снова используйте обновлённое содержимое `dist/public`.

## Важные пути

Все изображения и видео находятся в `client/public/media`; во время сборки они автоматически копируются в `dist/public/media`. Не перемещайте и не переименовывайте эти файлы без соответствующего изменения ссылок в `Home.tsx`.
